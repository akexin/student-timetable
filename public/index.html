日历订阅（同步到小米手机日历）

    

      
第 1 步：复制订阅地址

      

      
该地址无需登录，URL 中的令牌即为凭据。泄漏后请点下方「重置令牌」。

      

        
        
      

      

      
第 2 步：小米日历中添加

      
    
        
  1. 打开手机「日历」App → 右上角 ⋮ 菜单。
    2. 
        
  2. 进入 设置 → 日历订阅 / 添加订阅日历。
    3. 
        
  3. 粘贴上方地址 → 确认。注意：手机与运行本服务的电脑须处于同一局域网，且该电脑防火墙放行端口。
    4. 
        
  4. 回到日历 → 右上角 ⋮ → 勾选刚出现的日历名称即可显示。
    5. 
        
  5. 若希望立即刷新：下拉手动刷新，或等待约 1 小时自动同步。
    6. 
      

      

        
        
      

    

  







  

    
连接设置

    

      
      
服务启动时会在控制台打印 API Key；也可在 data/config.json 中查看。
        也支持在页面地址后追加 #key=你的密钥 自动填入。
